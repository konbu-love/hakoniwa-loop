# 箱庭ループシミュレーター

舞台・キャラ・勝利条件を入れるだけで、いつものAIの中でキャラクターが勝手に動き出す「箱庭遊び」のプロンプトを作るツールです。

ChatGPT、Gemini、Claudeなど、普段使っているAIのチャットにそのまま貼り付けて遊べます。

## 遊ぶ

https://konbu-love.github.io/hakoniwa-loop/

スマホのブラウザで動きます。インストールも登録もいりません。

## あそびかた

1. 舞台と「1周の終わり」を書く（例：お城の舞踏会／0時の鐘が鳴ったら）
2. キャラクターと、それぞれの勝利条件を書く（キャラは名前か設定のどちらかだけでもOK）
3. 「プロンプトを作ってコピー」を押す
4. いつものAIのチャットに貼り付けて送る
5. 1周終わったら、「★○○を追加」「○○を退場」「そのまま続行」「この世界線を続ける」などで次の周へ

## 入力する項目

| 項目 | 内容 |
| --- | --- |
| 舞台 | 物語の場所（必須） |
| 1周の終わり | 何が起きたら1周が終わるか。空欄ならAIが決めます |
| 最大周回数 | 何周で終わるか。空欄なら無制限 |
| 名前 | キャラの名前。空欄ならAIがキャラ設定に合わせて付けます |
| キャラ設定 | 性格や見た目など（例：ピンク髪の正ヒロイン）。空欄ならAIにおまかせ |
| 勝利条件 | そのキャラが叶えたいこと |
| ★記憶持ち | チェックすると、前の周をうっすら覚えたまま次の周に入ります |

## しくみ

### 勝利条件

キャラクターは、それぞれの勝利条件を叶えるために勝手に動きます。
勝利条件同士がぶつかるほど、予想外の展開が起きます。

例：

- ダンスに誘いたい王子と、0時までに料理を食べまくりたいシンデレラ
- おやつをあげたくない飼い主と、おやつが欲しい犬

### 周回（ループ）

「1周の終わり」に書いた出来事が起きたら、その周は終わりです。
1周終わると世界はリセットされ、同じ舞台・同じ初期状態で次の周が始まります。
手に入れたものや進んだ関係も、すべてリセットされます。

周の合間に、キャラを追加したり退場させたりできます。
面白い展開をそのまま続けたいときは「この世界線を続ける」と送ると、その周の終わりの状態を次の周に持ち越せます。

最大周回数を決めた場合、最後の周は全員が前の周をうっすら思い出し、エピローグで終わります。

### ★記憶持ちキャラ

★を付けたキャラは、前の周の出来事をうっすら覚えたまま次の周に入ります。
失敗を避けようとして動きますが、その善意が裏目に出ることもあります。

### 🏅金のしおり

各キャラには、表の勝利条件とは別に「隠し勝利条件」があります。
隠し勝利条件はAIがキャラ設定をもとに考え、周の終わりの金のしおり判定で初めて明かされます。
一度明かされた隠し勝利条件は、★記憶持ちキャラもうっすら覚えています。

全員の隠し勝利条件が満たされたとき、または誰も完全には勝っていないのに妙に安定して終わったとき、金のしおりを獲得できます。
ハッピーエンドとは限りません。

## コツ

- 有名なキャラクターは、名前だけで原作らしく動いてくれます
- 「1周の終わり」は、キャラが何もしなくても来るもの（時刻、チャイム、アラームなど）にすると、止めたい側のキャラにも勝ち目が出ます
- 強くも賢くもないキャラを★記憶持ちにすると、だいたい大変なことになります
- 世界観の違うキャラを途中で放り込むと、急に話が壊れて面白くなります

## 記録の残し方

- 全文を残したいときは、AIとのチャットをそのままコピーして保存してください
- 物語として読みたいときは、AIに「ダイジェストにして」と頼んでください
- 続きを別のAIや別の日に持ち越したいときは、AIに「設定・隠し勝利条件・途中で変えたことも全部入れて、引き継ぎを作って」と頼んでください

## 注意

- 実在の人物は登場させないでください
- 出てくる物語はAIが生成したものです。各AIサービスの利用規約に従って遊んでください
- AIによって、ルールの守り方には差があります
- 入力した内容はどこにも送信されません。プロンプトを作ってコピーするだけのツールです

## 中身

`index.html` ひとつだけで動きます。外部ライブラリは使っていません。
ダウンロードしてブラウザで開けば、そのまま使えます。
